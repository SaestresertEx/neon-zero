07 — FAQ

Read the signal clearly.

How many NEON/ZERO NFTs are planned?

Exactly 5,000, with the planned token range #0001 through #5000.

How is rarity structured?

The current project target is 60% Common, 25% Uncommon, 10% Rare, 4% Epic and 1% Legendary.

Are duplicate full combinations allowed?

No. The production framework is designed to block duplicate full-trait combinations.

Is $ZEROS live?

No. $ZEROS is currently documented as a planned ecosystem track. No official live token mechanics are declared here.

Do NFT holders automatically receive future rewards?

No automatic entitlement is declared. Any future program must publish eligibility and rules before activation.
